# HoAh-lite

录音 + OpenAI `gpt-transcribe` 转写的精简版。

## 启动
双击 **`HoAh-lite.vbs`**。第一次启动会自动安装运行环境（需要本机有 Python 3.12+），之后秒开。
开机自启：在“设置…”里勾选“开机自动启动”。

## 界面
- **悬浮条**：主窗口隐藏时出现的小条（录音按钮 + 计时 + 状态），置顶、不占任务栏，可拖动。双击打开主窗口；右键可开始/停止录音、切换音源、隐藏悬浮条、退出。
- **托盘图标**：打开主窗口、开始/停止录音、显示悬浮窗、开机自动启动、退出。录音时图标变红。
- **主窗口**：会话列表、转写结果、进度和错误。关闭主窗口只是隐藏，程序继续在托盘运行；从托盘“退出”才真正退出。

## 流程
1. 选音源（麦克风 / 系统声音 / 两者），开始录音。每条音轨每 5 分钟保存一个 MP3（16 kHz 单声道 64 kbps）到会话的 `chunks\` 子文件夹。
2. 停止后自动：合并成 `microphone.mp3` / `system.mp3` → 小于 25MB 直接上传；否则在停顿处切成 ≤20MB 的段，放到 `parts\` → 逐段转写。
3. 结果写入 `transcript.md`。失败时界面显示红色错误条；再次点击“转写 / 继续”会先清掉错误，并从失败的那段接着转。

数据目录：`%LOCALAPPDATA%\HoAhLite\sessions\<YYYYMMDD-HHMMSS>\`

## 转写参数
- `model=gpt-transcribe`，`stream=true`（实时显示文字）
- `languages[]`：设置里的语言，默认 `zh-cn, en`
- `keywords[]`：设置里的自定义词汇，每行一个，最多 100 个
- `prompt`：场景说明 + 同一音轨上一段结尾约 600 字
- 完全静音的音轨/分段不上传
